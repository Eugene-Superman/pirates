# Ship art

The ship in the game is a sprite atlas rendered in [Blender](https://www.blender.org/) (made with Blender 5.2).
Only the atlas in `public/sprites/` is loaded by the game; this folder is its source.

- `ship.blend` — the model and a ready render scene: a camera matching the game's isometric view, the sun, a plane that catches the shadow.
- `build_ship.py` — builds the model from scratch. Sizes, colors and the masts are set at the top of the file and in `MASTS`.
- `render_sprites.py` — renders 64 directions and packs the atlas into `public/sprites/ship-iso.webp` + `.json`.
- `textures/` — plank, sail and flag textures generated by `build_ship.py` (also packed into `ship.blend`).

Scale and axes match the game: 1 Blender unit = 1 game unit, the bow points to +X, the waterline is at Z = 0.

## Changing the ship

1. Open `ship.blend` in Blender.
2. By hand: edit the objects in the `Ship` collection.
   By code: Scripting → Open → `build_ship.py`, change the parameters, press Run Script
   (the `Ship` collection is rebuilt and manual edits in it are lost).
3. Save the `.blend`.
4. Scripting → Open → `render_sprites.py` → Run Script. On a GPU it takes a few minutes and Blender freezes meanwhile.
5. Reload the game page.
6. Commit `ship.blend` together with the re-rendered `public/sprites/`, so the source and the atlas stay in sync.

If you change the camera pitch or yaw (`CAMERA` in `src/client/scene/SceneView.ts`), update `CAM_PITCH` / `CAM_YAW`
in `render_sprites.py` and re-render the sprites.

Render frames (`frames/`), Blender backups (`*.blend1`) and `__pycache__/` are git-ignored.
The Python scripts run inside Blender and are not covered by `npm run check`.
